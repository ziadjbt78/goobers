### Known open items
1. MOCHI / ZIK slip + overstretch. Diagnosed: the force-step guard fires, plants,
   and the next frames re-measure the lock as out of reach, so the leg re-enters a
   forced-lift loop. The guard compares 3D hip->lock distance against
   `(L1+L2)*0.95` while the horizontal placement budget only reserves ~0.68x that.
   Proposed: one shared `reachBudget`; placement clamp `sqrt(budget^2 - dy^2)`;
   early lift at `0.92 * budget`; `duty` lowered from 0.62 to the measured stance
   fraction (~0.50-0.55).
2. Joint rate peaks 53-72 rad/s, every peak on a `plant` frame right after a
   guard-forced step. Same root cause as (1).
3. `Rig.ts` `axes` does not yet carry two probe-verified corrections: ZIK
   `limb` should be `'z'` (currently `'x'`) and MOCHI `wave` should be `+1`
   (currently `-1`). `signProbe` mutates these in memory only.
4. `freqRampProbe` returns 0 for PIP and all-zero for ZIK — unreliable; cadence
   figures come from `slipProbe` phase counting and `LocoConfig` arithmetic.
5. `strideProbe` `range` for ZIK reads ~0.0005 because the external-phase cycle
   barely moves ZIK's ankle.
6. Art: sky reads olive-green at night; foam arc reads as a semi-circle near the
   pond; rocks/bushes still read large next to creatures.
7. No GPU in the build sandbox (SwiftShader only, ~1 fps). 60 fps has never been
   verified by watching; all verification is fixed-step filmstrips.

## Architecture
- `src/engine/motion/` — the motion layer: `Locomotion` (phase from distance,
  never time), `Juice` (lift/squash/pitch/roll), `Face`/`FaceController`,
  `Choreo` (tool actions), `Dangle` (pick-up), `CreatureMotion` (pipeline +
  `RigAdapter`). `Rig.ts` is the adapter and the only place `axes` / `LocoConfig`
  live.
- Per fixed step: `brain -> desired velocity -> motion.preAnimate ->
  HeroAnimator.update -> motion.postAnimate`.
- `HeroAnimator` is the only code that writes bones. In the World it runs in
  **external-phase mode**: the caller supplies the gait cycle, the animator
  writes the in-place cycle, spine and arms, and the motion layer owns body
  attitude and the face. Juice is applied to the `body` bone (above the leg
  roots), never the `pivot` (below them).
- `Agent` is a driver: it computes desired velocity via `arrive()` and owns no
  position, heading or bone.
- Rigid skinning, one weight per vertex. Programs: toon, outline, flat, glossy,
  lit, foliage, emote, propOutline, vfxRing, vfxPuff.
- Deleted, do not resurrect: `render/sdf/`, `render/bakedSkinned/`, `toy/`,
  `engine/anatomy/`, `ui/debug/`, `core/Creature.ts`, `core/rng.ts`,
  `anim/springs.ts`.
